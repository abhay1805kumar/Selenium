# Selenium Web Scraping & Automation

A collection of Python scripts for learning and implementing web automation and web scraping using Selenium WebDriver.

## 🚀 Features

- Automate web browsers using Selenium WebDriver
- Locate single and multiple web elements
- Extract data from web pages
- Perform automated web interactions
- Store scraped data in CSV format
- Experiment with proxy-based requests

## 🛠️ Technologies Used

- Python
- Selenium WebDriver
- Chrome WebDriver
- CSV
